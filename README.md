# Giri in Moto

Web app (PWA) che propone giri in moto ad anello partendo da casa (la posizione si imposta nell'app e resta solo sul telefono).

- Scegli chilometri, tempo a disposizione e zona (province del Veneto, tutto il Veneto, confine trentino).
- Propone 3 giri passando dai ritrovi e dai passi frequentati dai motociclisti.
- Puoi modificare le tappe (tocca la mappa, trascina, rimuovi) e scaricare il **GPX** per il navigatore.
- Percorsi calcolati con OSRM (dati OpenStreetMap), mappe OpenStreetMap, libreria Leaflet.
